# I Know What I Saw

It was tall, it was in a hurry, and it was gone before I found my camera. I'm writing it down
anyway. This is the first entry in my field notes.

It's also your first post. Every Markdown file in `src/posts/` is a post: `posts.json` gives
them all the layout and the `posts` tag, so they show up on the home page, newest first. The
`tags` in a post's front matter add it to a page for each tag (this one's on
[sightings](https://example.com/tags/sightings/index.md)), and every post is in the feed, `/feed.xml`
(`feedPlugin()` in `ssqch.config.js`).

Edit this file while `ssqch serve` is running, and the page reloads by itself.
