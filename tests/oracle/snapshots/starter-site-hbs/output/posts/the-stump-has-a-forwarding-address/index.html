The Stump Has a Forwarding Address

February 5, 2026

This entry used to be at /posts/where-did-the-stump-go/. I renamed it, because the stump didn't go anywhere: it has a forwarding address. A ranger had already pinned the old link to the station's notice board, and it still works. Try it: the old address.

A post's address comes from its file name, so renaming the file moves the post. The old address goes in the post's front matter:

aliases: [/posts/where-did-the-stump-go/]

redirectsPlugin() in ssqch.config.js gives each old address a small page that sends readers, and search engines, on to the new one. An old address that's another page's address stops the build, so a redirect never hides a post.

On Netlify or Cloudflare, redirectsPlugin({ hostFile: true }) writes each one to _redirects instead, and the host answers with a real 301.

The tracks lead back to the stump. They always do.
