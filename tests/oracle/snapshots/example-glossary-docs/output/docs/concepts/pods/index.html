Pods

On this page

A pod is the unit you deploy. Every pod runs on one node.

Pod lifecycle

A pod is pending, then running, then finished. The ranger on its node reports each change.

Don't share snacks

Squatches in different pods can't share snacks. Put them in one pod if they must.

Working with pods

Note

Most of the time you don't create pods yourself; a herd creates them for you.
