Installation

ssqch runs on Node.js 22.18 or newer, and comes from npm. Install it in the site as a dev dependency, so the lockfile pins the version:

npm

npm init -y
npm install --save-dev ssqch

pnpm

pnpm init
pnpm add -D ssqch

Then run it with npx ssqch (or pnpm ssqch), or by name in a package.json script: "build": "ssqch build". To have ssqch on your PATH for every site, npm install --global ssqch or brew install reverentgeek/tap/ssqch.

Run the site #

npx ssqch serve

Open http://localhost:8080. Pages rebuild and the browser reloads as you save, and that includes ssqch.config.js.

Build it #

npx ssqch build

The site is in dist/, ready for any static host. A broken link or a page without a title stops the build and says where.

SEARCH=1 npx ssqch build also builds a search index with Pagefind and adds a search button to the header (or press Ctrl+K, or Cmd+K on a Mac). Pagefind is a program of its own, which npx fetches for that one step, at the version ssqch.config.js pins. npx ssqch serve builds without it, so to try search, build with it and serve that build: SEARCH=1 npx ssqch build, then npx ssqch serve --built.
