This is your first post. Every Markdown file in `src/posts/` is a post: `posts.json`
gives them all the layout and the `posts` tag, so they show up on the home page.

Edit this file while `ssqch serve` is running, and the page reloads by itself. Start your
next post with `ssqch new posts --title "My second post"`: it copies
`src/_archetypes/posts.md` and fills in the title and today's date.
