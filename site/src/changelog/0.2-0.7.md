SiteSquatch's first release was 0.2.0, on 8 November 2026, and it started by saying goodbye to Eleventy compatibility: an ssqch config is `defineConfig({ ... })`, an object, instead of a list of `addFilter()` calls. The 0.x releases that followed, up to 0.7.1, were ssqch written in Rust, and most of what you use today arrived in them.

## The headlines

- **0.3: more template languages.** Liquid, Nunjucks and Jinja, Handlebars and Mustache joined in, and `templateEngineOverride` became `render`.
- **0.4: the Sasquatch voice,** plus `base` for a site served under a path, `ssqch import eleventy`, themes, custom elements that load only where they're used, and the docs starter. Markdown gained heading ids, footnotes, alerts and containers by default.
- **0.5: built for coding agents.** `ssqch init` writes an `AGENTS.md`, and `ssqch docs` answers from the installed version, with no network. `ssqch footprint` and `budgets` say what a build weighs, archetypes became blueprints, and Jinja became the default.
- **0.6: a stricter link checker.** It reads feeds, the sitemap, `<meta>` URLs and JSON-LD too, and `ssqch serve --built` serves a build the way a host would.
- **0.7: found moving lit.dev from Eleventy.**

## What you might need to change

If you're on 0.7 or earlier, start with the 0.8 entry: it's the one that changes how ssqch is installed. Each older release's breaking changes are in its own section of the changelog, with what a site had to change.
