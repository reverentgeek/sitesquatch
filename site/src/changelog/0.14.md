We handed ssqch to an agent that had never seen it, asked for a snack company's website, and wrote down every place it stumbled. This release is what we fixed.

## The headlines

- **Budgets with teeth.** Add `fail: true` to `budgets`, and a page that grew too big stops the deploy instead of scrolling past as a warning.
- **Errors that say what to change.** A front matter value with a second `: ` tells you to quote it. A schema problem on a paginated page names the item it's on. A misspelled field is one error, not two.
- **Know what AI may read.** `ssqch patrol` reads your `robots.txt` the way each AI crawler does: training refused, search allowed, at a glance.
- **Quiet means quiet.** `--quiet` holds a build tool's banner until the tool fails.
- **Starters that catch typos.** New sites turn on `strict`, pin their dates to UTC and git, and get copy-a-link headings in the docs starter.
- **A searchable directory example**, with filters and Pagefind.

## What you might need to change

- **`redirectsPlugin({ netlify: true })` is `hostFile: true`.** Cloudflare reads `_redirects` too. With it on, redirect pages are off by default, since a host would serve the page instead of the 301; add `pages: true` to keep them.
- **A redirect pattern, an old address with a `*` or a `:name` in it, needs `hostFile: true`.** Only a host can match one.
- **`page.outputPath` starts from your project** (`./dist/about/index.html`), so a page prints the same everywhere. Need the whole path? `path.resolve(page.outputPath)`.
