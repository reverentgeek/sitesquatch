ssqch 0.8 is a TypeScript program on Node, installed from npm. That's a big change under the hood, and almost none of it shows up in your site: the commands, the config, the JSON reports and the voice are the same as 0.7's, and the blog, the examples and the starters build to the same bytes (apart from the images, which a new encoder makes). Most sites change nothing.

## The headlines

- **Install it like any other dev dependency.** `npm install --save-dev ssqch`, on Node 22.18 or newer. sharp is its one dependency, and Homebrew's formula installs the same npm package.
- **Your config runs on real Node.** Every npm package and every Node built-in works in your config and data files, because Node is what loads them.
- **Images are encoded by sharp.** The defaults are 0.7's settings converted, so a site that doesn't set them encodes as it did.
- **Plugins written in Rust are `.wasm` files**: one file that runs on every platform, with nothing to compile when a site installs it.
- **Highlighted code is kept between builds**, so a fresh `ssqch build` skips loading the grammars. The ReverentGeek blog's build takes 0.64 s instead of 1.0 s.

## What you might need to change

- **Installing:** there's no standalone binary anymore. In GitHub Actions, swap `setup-ssqch` for `actions/setup-node` and `npm ci`, and delete 0.7's binary from `~/.cargo/bin` so it doesn't shadow the new one.
- **Your JavaScript:** filters get your real objects, so copy before you sort (`[...posts].sort()`). A CommonJS package might need a default import instead of named ones.
- **Data:** YAML dates are dates in every key, and `017` is the number 17, so quote a value that needs to stay text (a ZIP code, say).
- **Templates:** Jinja and Nunjucks render with ssqch's fork of Nunjucks, Liquid is liquidjs, and Edge is edge.js 6.5. Most templates render as they did, and the full notes list the differences.
- **Images:** the quality options are sharp's numbers now, and `avifEffort` replaces `avifSpeed`.
- **Rust plugins:** 0.7's Rust API is gone. A Rust plugin is a crate built with `ssqch-plugin`.
