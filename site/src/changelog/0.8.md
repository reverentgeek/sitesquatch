SiteSquatch traded its old boots for a new pair in 0.8: it runs on Node now, and installs from npm. What does that mean for your site? Probably nothing! The commands, the config, the reports and the deadpan voice all stayed put, and the blog, the examples and the starters build to the same bytes (apart from the images, which a new encoder makes). What you get is an install that works like every other dev dependency, and a config where the npm packages you already know just work.

## The headlines

- **Install it like everything else.** `npm install --save-dev ssqch` and you're packed, on Node 22.18 or newer. Homebrew's formula installs the same package.
- **Any npm package, right in your config.** Your config and data files run on real Node, so every package and built-in you already use works there.
- **Faster second trips.** Highlighted code is kept between builds, so a fresh `ssqch build` skips loading the grammars. The ReverentGeek blog builds in 0.64 s instead of 1.0 s.
- **Images come out the way they did.** sharp encodes them now, starting from 0.7's settings, so a site that never touched the image options encodes as it did.
- **Rust plugins travel light.** A plugin written in Rust is one `.wasm` file that runs on every platform, with nothing to compile when a site installs it.

## What you might need to change

- **Installing:** there's no standalone binary anymore. In GitHub Actions, swap `setup-ssqch` for `actions/setup-node` and `npm ci`. Then leave no trace: delete 0.7's binary from `~/.cargo/bin`, so it doesn't shadow the new one.
- **Your JavaScript:** filters get your real objects, so copy before you sort (`[...posts].sort()`). A CommonJS package might need a default import instead of named ones.
- **Data:** YAML dates are dates in every key, and `017` is the number 17, so quote a value that needs to stay text (a ZIP code, say).
- **Templates:** Jinja and Nunjucks render with ssqch's fork of Nunjucks, Liquid is liquidjs, and Edge is edge.js 6.5. Most templates render as they did, and the full notes list the differences.
- **Images:** the quality options are sharp's numbers now, and `avifEffort` replaces `avifSpeed`.
- **Rust plugins:** 0.7's Rust API is gone. A Rust plugin is a crate built with `ssqch-plugin`.
