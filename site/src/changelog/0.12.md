Coming from VitePress? This release is for you. We moved a big VitePress docs site with a coding agent, wrote down everything it had to build by hand, and then moved it again. The second time, ssqch did most of that work itself.

## The headlines

- **Scout knows VitePress.** `ssqch scout` reads your `.vitepress/config.ts`, lists what your pages use (every component by name, with the file it comes from), and drafts a config that builds your site on the first try. Run it again halfway, and the list really does get shorter.
- **Your Vue components, rendered.** `vuePlugin()` renders the components your pages use with your own Vite and Vue, data loaders included, and with `hydrate`, your demos still click and toggle in the browser.
- **VitePress's Markdown in one line.** `markdown: { dialect: "vitepress" }` brings its containers, code groups, heading anchors and links along, as VitePress writes them.
- **Components as tags.** Write `<Badge type="tip" />` in a page, and `_includes/components/Badge.*` renders it. No framework needed.
- **A site for language models.** `llmsPlugin()` writes `llms.txt` and a Markdown copy of every page, so agents read your docs as you wrote them.
- **Proof the words made it.** `ssqch diff --text` tells you how much of each page's text matches, word by word: 99.9% of 125,249 words, on our VitePress move.

## What you might need to change

Nothing. Each of these is new, and your site builds as it did.
