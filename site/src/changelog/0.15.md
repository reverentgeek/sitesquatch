We sent an agent back to build the Squatch Snacks website a second time. It found what the first trip walked right past, and this release fixes it.

## The headlines

- **Every page gets checked.** A schema on a tag checks every page a paginated template makes, not only the first, and an error names the item it's on (`item 4 of snacks, "Moss Mix"`).
- **Dates stay on their day.** Write `date: 2026-11-02` and your own code prints the 2nd, whatever your `timeZone` is.
- **No more hiding behind a 404.** The link checker reads `_redirects` the way Netlify does, so a catch-all to your 404 page no longer passes every broken link.
- **Whole addresses on every site.** `absoluteUrl` works without the feed plugin, and `import { withBase, absoluteUrl } from "ssqch"` gives your own code the site's `base`.
- **Leave no trace means it.** A photo you removed takes its copies with it.
- **A company website example**: product pages from a data file, pricing, careers and structured data.

## What you might need to change

- **Schemas check every page now.** Bad data on a later page fails the build: fix the data.
- **A catch-all 404 line isn't a redirect.** Broken links it used to cover now fail a production build. Fix the links.
- **A date without a time is midnight in your `timeZone`.** East of UTC, code that prints one with `getUTCDate()` or `toISOString()` now gets the day before: switch to the local methods, as the starters' `readableDate` and `isoDay` do.
- **`absoluteUrl` from `ssqch/rss` adds your `base`.** If you added it yourself, you still get it once.
