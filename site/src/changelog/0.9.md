This release came out of moving two real sites to ssqch: opensource.guide (from Jekyll) and expressjs.com (from Astro). Most of what's new here is something one of them tripped over on the way.

## The headlines

- **Liquid behaves like Jekyll's.** Math filters and `split` work the way Ruby's Liquid does, `{% include_relative %}` works, and a function in your config can be a Liquid tag, so a Jekyll plugin's tag has somewhere to go. The whole trip has a trailhead now: `ssqch docs --from jekyll`.
- **The same build on your laptop and in CI.** `timeZone: "UTC"` pins the time zone your site's own JavaScript runs in, and `SOURCE_DATE_EPOCH` pins the build's time. Before this, v8.dev's dates came out different on 137 pages between two time zones.
- **`ssqch diff` takes three or more folders** and lists what varies between builds that should be identical. That's the first thing worth knowing before you start a migration.
- **Liquid's `where` got a lot faster.** A layout that looks pages up in a collection on every page builds 8.6 times faster, and opensource.guide's port went from 6.8 s to 1.4 s!

## What you might need to change

- **Heading ids** now follow GitHub's slugger character for character. A heading with an accent, an emoji or a superscript can get a new id, so check links to those anchors, or give the heading an id of its own (`## x² {#x2}`).
- **Pages without a date** sort after the dated ones, in path order. If you counted on the old order, give those pages dates.
- **Liquid's `split`** drops empty strings at the end (`"a,b,,"` is two items), and a block that only sets variables doesn't write blank lines anymore.
- **A `computed` value named `page`** is an error now. It was being thrown away quietly, so give it another name.
- **`slot` is a container name** now. If you have a container called `slot`, rename it.
