---
title: Installation
description: "Install Pinecone Native 1.0's command line tool with npm or yarn, then create your first app."
---
Install the command line tool with your package manager:

:::: tabs
::: tab npm
```sh
npm install -g pinecone-native@1.0
```
:::
::: tab yarn
```sh
yarn global add pinecone-native@1.0
```
:::
::::

Then create an app:

```sh
pinecone-native init MyApp
```
