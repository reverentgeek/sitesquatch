---
title: Installation
description: "Install Pinecone with a package manager or build it from source, and what your forest needs first: at least one clearing."
---
## With a package manager

```sh
brew install pinecone
```

## From source

```sh
git clone https://example.com/pinecone.git && cd pinecone && make install
```

> [!NOTE]
> Pinecone needs a forest with at least one clearing.
